# React Learning Roadmap

## 📍 Your Learning Path

This roadmap guides you from React beginner to confident developer. Follow it sequentially for best results.

---

## Phase 1: Foundations (Weeks 1-2)

### 1. Prerequisites ✅
Before starting React, ensure you know:
- **HTML**: Semantic elements, forms, attributes
- **CSS**: Selectors, flexbox, grid, responsive design
- **JavaScript (ES6+)**:
  - Variables (`let`, `const`), Functions (arrow functions)
  - Arrays & Objects (destructuring, spread operator)
  - Array Methods (`map`, `filter`, `reduce`, `find`)
  - Promises, Async/Await
  - Modules (`import`/`export`)

**Resources:**
- MDN Web Docs for JavaScript
- JavaScript.info for modern JS

---

### 2. React Fundamentals 📚
**Location:** `Notes/01-fundamentals/`

Master these core concepts:
- ✅ **JSX** - HTML-like syntax in JavaScript
- ✅ **Components** - Building blocks of React apps
- ✅ **Props** - Passing data to components
- ✅ **State** - Managing component data
- ✅ **Event Handling** - Responding to user interactions
- ✅ **Conditional Rendering** - Show/hide UI based on conditions
- ✅ **Lists** - Rendering arrays of data
- ✅ **Forms** - Controlled components

**Practice Project:** Build a simple counter, todo list, or profile card

---

## Phase 2: React Hooks (Weeks 3-4)

### 3. Essential Hooks 🎣
**Location:** `Notes/02-hooks/`

Learn hooks in this order:
1. ✅ **useState** - Local component state
2. ✅ **useEffect** - Side effects (API calls, subscriptions)
3. ✅ **useRef** - DOM references, persisting values
4. ✅ **useReducer** - Complex state logic
5. ✅ **useContext** - Global state without prop drilling
6. ✅ **Custom Hooks** - Reusable stateful logic

**Practice Project:** Build a data fetching component, timer, or form with validation

---

## Phase 3: Routing & Styling (Week 5)

### 4. Routing 🛣️
**Location:** `Notes/03-routing/`

- ✅ React Router basics
- ✅ Dynamic routes & parameters
- ✅ Nested routes
- ✅ Protected routes
- ✅ Programmatic navigation

**Practice Project:** Multi-page app with navigation

---

### 5. Styling 🎨
**Location:** `Notes/04-styling/`

Choose your approach:
- ✅ **CSS Modules** - Scoped CSS (good default)
- ✅ **Tailwind CSS** - Utility-first (modern, popular)
- Styled Components (optional, later)

**Practice Project:** Style your previous projects

---

## Phase 4: Forms & Data (Week 6)

### 6. Forms 📝
**Location:** `Notes/05-forms/`

- ✅ Controlled components
- ✅ Form validation
- ✅ **React Hook Form** - Modern form library

**Practice Project:** Login/signup form, contact form, multi-step form

---

### 7. API Integration 🌐
**Location:** `Notes/06-api/`

- ✅ Fetch API
- ✅ Async/Await
- ✅ Loading & error states
- ✅ Abort controllers
- Axios (optional alternative)

**Practice Project:** Fetch and display data from a public API

---

## Phase 5: State Management (Weeks 7-8)

### 8. Advanced State 🗄️
**Location:** `Notes/07-state-management/`

- ✅ **Context API + useReducer** - Built-in state management
- Zustand (optional, for larger apps)
- Redux Toolkit (only for large team projects)

**Practice Project:** Shopping cart, auth system, or dashboard

---

## Phase 6: Advanced Concepts (Weeks 9-12)

### 9. Performance Optimization ⚡
- React.memo - Prevent unnecessary re-renders
- useMemo - Memoize expensive calculations
- useCallback - Memoize functions
- Lazy loading & code splitting

---

### 10. Advanced Patterns 🏗️
- Higher Order Components (HOC)
- Render Props
- Compound Components
- Portals
- Error Boundaries

---

### 11. TypeScript with React 📘
Start learning TypeScript alongside React:
- Type props and state
- Type hooks
- Generic components
- Type API responses

**Tip:** Don't wait until the end to learn TypeScript!

---

### 12. Testing 🧪
- Jest - Test runner
- React Testing Library - Component testing
- Unit tests
- Integration tests

---

## Phase 7: Production Skills (Weeks 13-16)

### 13. Server State Management 🔄
- **TanStack Query (React Query)** - Recommended
- SWR (alternative)

These replace manual fetch logic with caching, refetching, and more.

---

### 14. Authentication & Security 🔐
- JWT Authentication
- OAuth (Google, GitHub login)
- Protected routes
- Secure token storage
- HTTPS, CORS

---

### 15. React Ecosystem 🌟
- **Next.js** - Most important framework (SSR, SSG, API routes)
- Remix (alternative to Next.js)
- Vite (already using) - Build tool
- Webpack (good to know)

---

### 16. Real-World Development 💼
- Folder structure best practices
- Reusable component libraries
- API services layer
- Environment variables
- Error handling
- Logging
- Deployment (Vercel, Netlify, AWS)

## 📊 Learning Tips

### Do's ✅
- Code along with tutorials
- Build projects to practice
- Read error messages carefully
- Use React DevTools
- Join React communities
- Read official documentation
- Practice daily (consistency > intensity)

### Don'ts ❌
- Don't skip fundamentals
- Don't copy-paste without understanding
- Don't learn too many things at once
- Don't get stuck on perfection
- Don't ignore errors
- Don't memorize - understand concepts

---

## 🎓 Recommended Learning Order

1. **Weeks 1-2:** Fundamentals (JSX, Components, Props, State)
2. **Weeks 3-4:** Hooks (useState, useEffect, useContext, Custom Hooks)
3. **Week 5:** Routing & Styling
4. **Week 6:** Forms & API Integration
5. **Weeks 7-8:** State Management (Context + useReducer)
6. **Weeks 9-12:** Advanced concepts & TypeScript
7. **Weeks 13-16:** Production skills & frameworks
